# Corpus

Los PDF originales de la cátedra **no se suben al repositorio** (material con autoría;
el repo podría ser público). Se guardan localmente en `corpus/_raw/` (ignorado por git).

Por documento se versiona:
- `meta.md` — fuente, versión, autores, contenido por página.
- `hallazgos.md` — observaciones y candidatos a inconsistencia.
- `modelo/*.json` — transcripción al modelo canónico (estado: borrador / validado).
